# 🚀 OpenAI Multimodal AI Playground

A beginner-friendly project demonstrating how to build AI-powered applications using the latest OpenAI Python SDK. This notebook explores text generation, vision understanding, image generation, image editing, and a simple personal AI assistant.

---

## 📌 Project Overview

This project showcases the core capabilities of OpenAI's APIs through practical Python examples. It is designed as a learning resource for developers interested in building multimodal AI applications.

The notebook covers:

- 💬 Text Generation
- 🤖 Personal AI Assistant
- 📧 Email Summarization
- 👁️ Vision API (Image Understanding)
- 🎨 AI Image Generation
- 🖼️ AI Image Editing
- 🔐 Secure API Key Management

---

## ✨ Features

- Generate text responses using GPT models
- Build a simple AI assistant
- Summarize long emails
- Analyze images using Vision API
- Generate images from text prompts
- Edit existing images using prompts
- Save generated images locally
- Learn Base64 encoding and decoding
- Understand the latest OpenAI SDK workflow

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/OpenAI-Multimodal-AI.git

cd OpenAI-Multimodal-AI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## 🔑 API Key Setup

Create a `.env` file in the project root.

```env
OPENAI_API_KEY=your_api_key_here
```

Never upload your API key to GitHub.

---

## ▶️ Running the Notebook

Open the notebook:

```bash
jupyter notebook
```

or

```bash
jupyter lab
```

Run each cell sequentially.
